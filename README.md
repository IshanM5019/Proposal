# Will You Be Mine? 💕 — Romantic Proposal Website

A modern, responsive, and animated romantic proposal website built with vanilla HTML5, CSS3, and modern JavaScript.

## ✨ Features & Highlights

- **Luxury Romantic Aesthetics**: Deep velvet gradient background with animated aurora mesh, soft glowing bokeh lights, and floating hearts with gentle parallax.
- **Modern Typography**: Curated Google Fonts pairing:
  - *Playfair Display* (Editorial luxury headlines)
  - *Sacramento* & *Dancing Script* (Romantic handwritten calligraphy)
  - *Plus Jakarta Sans* (Crisp modern body text)
- **Interactive 3D Tilt Card**: The proposal card dynamically tilts in 3D space tracking mouse movements.
- **Ultra-Smooth Runaway "NO" Button**:
  - Playfully dodges when hovered or tapped on mobile with spring physics.
  - Dynamically cycles through 10 cute pleading messages (*"Are you sure? 🥺"*, *"Look how bright YES is! ✨"*, *"Free hugs for life! 🫂"*).
  - Keeps safe margins so it never gets lost off-screen.
  - Each dodge subtly expands the **YES! ❤️** button and increases its radiant glow.
- **Spectacular Celebration Screen**:
  - Triggers on clicking **YES! ❤️** with fanfare audio chords and realistic fluttering rose petals, floating hearts, and golden confetti.
  - **💌 Love Letter**: Interactive wax-sealed note with customized promises.
  - **✨ 8 Reasons Why I Love You**: Interactive cards with sweet personal reasons.
  - **🎟️ Love Coupons**: Tap-to-redeem romantic coupons (*Ice cream run*, *Warm hugs*, *Dinner date*).
  - **📜 Official Certificate of Eternal Love**: Beautiful certificate with names and date, with a **Save / Print** option!
- **Web Audio API Sound Engine**:
  - 100% self-contained synthesized sounds — no external audio files required!
  - Soft chimes, playful dodge whistles, celebration fanfare, and an ambient romantic lullaby loop (*Romantic Melody*).
- **Multiple Color Themes**:
  - 🌹 *Blush Rose* (Default: Romantic ruby & rose gold)
  - 🌌 *Midnight Starlight* (Deep velvet purple & celestial gold)
  - 🌸 *Cherry Blossom* (Pastel sakura pink)
- **Live Personalization**:
  - Tap the **Personalize** button in the header to set her name, your name, and a custom message.
  - Generates shareable query link (e.g. `?to=Angel&from=Ishan`).

## 🚀 Running Locally

You can open `index.html` directly in any web browser, or serve it locally:

```bash
# Using Python
python -m http.server 3000

# Or using npx
npx serve .
```

Open `http://localhost:3000` in your browser.

## 🌐 Deploying to Vercel

Since this is a standard static web application, deploying to Vercel is instantaneous:

```bash
npx vercel deploy --prod
```
Or connect your GitHub repository to Vercel.
